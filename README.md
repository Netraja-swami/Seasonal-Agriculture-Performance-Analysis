# 🌾 Seasonal Agriculture Performance Analysis

A comprehensive data analysis project examining agricultural performance across Indian seasons (Kharif, Rabi, Zaid) using Python.

## 📊 Dataset
- 4,000 farm records | 28 features | 8 states | 8 crop types | 3 seasons

## 🔍 What's Analyzed
- Seasonal yield, profit & revenue comparison
- Crop-wise profitability (which crops win/lose)
- Environmental factors impact on yield
- Irrigation methods & water efficiency
- State-wise regional performance
- Loss farm investigation (why 49% farms fail)

## 🛠️ Tech Stack
- Python | Pandas | NumPy | Matplotlib | Seaborn | SciPy | Jupyter Notebook

## 💡 Key Findings
- Kharif is the most profitable season (avg profit ₹1,78,915/farm)
- Zaid season averages NEGATIVE profit (-₹24,805/farm)
- Sugarcane & Chilli are the only consistently profitable crops
- Drip irrigation gives 43% higher yield than rainfed farming
- 49% of all farms are running at a loss — systemic issue
